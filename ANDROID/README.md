# Точки — Android (dotgame)

Мобильная версия игры «Точки» (dotgame) для Android. Та же концепция, что и
десктопная MAID-версия: точки, контуры, захват, самопожертвование, без
оживления. **Только человек vs человек** (без бота). Управление — сенсорное.

## Запуск APK

Собранный APK: `dotgame-android-v1.2.apk` (в корне этой папки).

Установка на телефон:
1. Скопируйте `dotgame-android-v1.2.apk` на телефон.
2. Разрешите установку из неизвестных источников.
3. Откройте файл — установится приложение «Точки».

Или через adb (телефон подключён по USB, включена отладка):
```
adb install dotgame-android-v1.2.apk
```

Параметры: пакет `ru.maid.dotgame`, minSdk 24 (Android 7.0+), targetSdk 36.

## Управление (сенсорное)

| Жест | Действие |
|------|----------|
| **Тап** по пустому месту (1-й) | Призрак: видно, куда встанет точка (окружение связи + линии к соседям) |
| **Тап** (2-й, рядом с призраком) | Подтвердить — точка ставится по-настоящему |
| **Тап** (2-й, в другом месте) | Призрак переезжает туда (новый предпросмотр) |
| Перетаскивание одним пальцем | Панорама |
| Щипок двумя пальцами | Зум **к пальцам** (до ×100) + панорама |
| **Два быстрых тапа** (два пальца) | Отменить ход (undo) |
| Кнопка ↩ | Отменить ход |
| Кнопка ⟲ | Новая игра (с подтверждением) |
| Кнопка ? | Правила |

**Универсальный механизм постановки** (без выделения линий). Призрак сам
прилипает к «интересной» позиции и подсвечивается:
* **Зелёный** — на пересечении *своей* линии/круга со своей, чужой линией
  или с границей карты. Точка ставится точно в пересечении.
* **Жёлтый** — на *своей* линии/круге в любом месте, либо на границе карты
  (граница доступна обоим игрокам).
* **Обычный** (цвет игрока) — свободная постановка.

Чисто чужие пересечения (где нет ни одной *своей* линии) ставить нельзя —
призрак там будет обычным. Круги досягаемости всегда видны тонко.

**Предупреждение**: если призрак стоит внутри чужого контура, вокруг него
оранжевое кольцо — точка будет захвачена сразу (самопожертвование).

## Правила

* Ходят по очереди: красные, затем синие.
* Точки на расстоянии ≤ R соединяются линией.
* Замкнутый контур **захватывает** чужие точки внутри: они гаснут и идут в счёт.
* Точка, поставленная внутрь чужого контура, **захватывается сразу**.
* Захваченная точка неактивна навсегда (без оживления).
* Побеждает тот, у кого больше захваченных.

## Структура

```
ANDROID/
  www/                  # веб-приложение (ядро + UI)
    index.html
    css/style.css
    js/core.js          # ядро игры (перенос с Python 1:1, покрыто тестами)
    js/ui.js            # Canvas-рендеринг + сенсорное управление
  android/              # нативный Android-проект (Capacitor)
  test/                 # дифференциальные тесты порта Python->JS
    gen_cases.py        # генерация позиций + Python-ссылка
    run_js.js           # прогон через JS-ядро (Node)
    compare.py          # сравнение py vs js vs перебор
    gen_game.py         # случайные партии в Python
    run_game_js.js      # те же ходы в JS
    compare_game.py     # сравнение состояний партий
  capacitor.config.json
  package.json
  dotgame-android-v1.2.apk   # собранный APK
```

## Сборка APK

Требования: Node 18+, JDK 21, Android SDK (platform 36, build-tools 36).

```
cd ANDROID
npm install
npx cap add android        # один раз (создаёт android/)
# настроить android/local.properties: sdk.dir=/путь/к/android-sdk
npx cap sync android       # скопировать www в android/
cd android
JAVA_HOME=/путь/к/jdk21 ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Важно: Capacitor 8 требует **JDK 21** (не 17 и не 25). Gradle 8.14 не работает
на Java 25.

## Проверка порта (Python -> JS)

Ядро `core.js` — перенос `MAID/dotgame_maid.py`. Верность порта проверена
дифференциальными тестами в `test/`:
* Геометрия (предикат «точка в контуре»): 1500 позиций / 12 539 запросов,
  JS == Python == полный перебор циклов, 0 расхождений.
* Логика игры: 60 партий × 40 ходов, финальные состояния Python == JS,
  0 расхождений.

Запуск:
```
cd ANDROID/test
../../MAID/.venv/bin/python gen_cases.py && node run_js.js && ../../MAID/.venv/bin/python compare.py
../../MAID/.venv/bin/python gen_game.py && node run_game_js.js && ../../MAID/.venv/bin/python compare_game.py
```

## Отличия от десктопной версии

* Нет бота (только человек vs человек).
* Управление сенсорное (два тапа вместо ЛКМ).
* Постановка — универсальный механизм: призрак сам подсвечивается жёлтым
  (на своей линии/границе) или зелёным (на пересечении), без выделения линий
  через ПКМ как на десктопе.
* Нет клавиш Z/R/H — вместо них жесты и кнопки.
* Ядро перенесено на JavaScript (1:1 по алгоритму).
