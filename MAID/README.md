# Игра в точки — MAID

Собранная версия игры мастера: синтез всех версий (`dotgame.py` …
`dotgame2026_manual.py`) в папке `..` без их центральной проблемы —
экспоненциального перебора простых циклов.

Оригиналы не изменяются, всё живёт в этой подпапке.

## Запуск

```sh
cd /run/media/mmn/HDD\ 2TB/^CODE^/DOTGAME/MAID
./.venv/bin/python dotgame_maid.py          # два игрока
./.venv/bin/python dotgame_maid.py --ai     # компьютер за синих
./.venv/bin/python dotgame_maid.py --aibot  # компьютер против компьютера
```

(venv с pygame-ce уже создан: `./.venv`.)

## Проверки (без скриншотов, полностью программные)

```sh
./.venv/bin/python test_maid.py     # 64 проверки: ядро, оракул, производительность, ИИ
./.venv/bin/python smoke_maid.py    # 51 проверка: живой UI-цикл, реальные события pygame
./.venv/bin/python stress_test.py   # 25 проверок: усиленное (50k запросов оракула, 14k ходов)
```

`test_maid.py` включает встроенный оракул: геометрический предикат
«точка в контуре» сверяется с полным перебором циклов на сотнях
случайных позиций.

`stress_test.py` — усиленное тестирование: дифференциальный тест
предиката на 6000 позициях / 50k запросов (9 видов, включая вырожденные:
коллинеарные, вложенные контуры, самопересечения, общие рёбра, точки
ровно на границе) + инварианты логики игры на 14 400 случайных ходах
(согласованность счёта, точность undo, корректность clone, режим с
оживлением, производительность на плотных кластерах).

## Правила (решения мастера от 06.11.2026)

* Круглое поле радиуса 350, красные ходят первыми.
* Точки одной стороны соединяются линиями, если расстояние ≤ 50.
* Закрытая цепочка линий — контур: чужая точка внутри (или на линии)
  контура захватывается и становится неактивной **наВСЕГДА**
  (`REACTIVATION = False`; вернуть оживление можно флагом
  `REACTIVATION = True`).
* Самопожертвование сохраняется: точка, поставленная внутрь чужого
  контура, захватывается при рождении и идёт в счёт противнику.
* Счёт — число захваченных точек.
* Лимит точек на сторону — `MAX_POINTS_PER_PLAYER` (0 = без лимита).

## Управление

| Действие | Клавиша/кнопка |
|---|---|
| Поставить точку | ЛКМ |
| Выбрать линию (граница поля / окружность точки / ребро) | ПКМ |
| Кандидаты на пересечениях выбранной линии | ПКМ повторно по той же линии |
| Точная постановка по кандидату | ЛКМ |
| Сдвиг камеры | СКМ (тянуть) |
| Масштаб | колесо |
| Отменить ход | Z |
| Новая игра | R |
| Справка | H |
| Снять выделение линии | Esc |

## Что здесь есть, чего не было в версиях мастера

* **Геометрический предикат** вместо перебора циклов: планарное
  вложение немостовых рёбер + обход граней O(V+E), запрос O(E).
  Кластер в 10+ точек больше не зависает (проверено оракулом:
  16828 конфигураций, 0 расхождений).
* **Локальный ИИ** (`SimpleAI`, режимы `--ai`/`--aibot`): кандидаты на
  той же геометрии, что и привязка; двухслойная оценка — выгода хода
  (захваты, новый цикл, почти-захваты) минус выгода лучшего ответа
  противника; самопожертвование только в безвыходном положении.
* **UX**: отмена (Z), сброс (R), справка (H), вспышки захвата,
  подсветка последнего контура, лимит точек и экран конца игры,
  привязка к линиям с зелёными кандидатами, зум и панорама.

## Файлы

* `dotgame_maid.py` — игра (ядро + ИИ + UI, один файл).
* `test_maid.py` — проверки ядра (не нужен дисплей).
* `test_oracle.py` — самодостаточный оракул (полный перебор циклов + аналитика клики), от которого зависят тест [10] и stress_test.
* `smoke_maid.py` — проверки живого UI (headless, SDL_VIDEODRIVER=dummy).
* `stress_test.py` — усиленное тестирование (оракул 50k запросов + инварианты логики на 14k ходов).
* `shots/` — старые скриншоты от предыдущей (пиксельной) версии smoke;
  проверки через них больше не используются.
