# Euler Dot Game

Стратегическая игра «Точки» на двоих (человек vs человек). Игроки по
очереди ставят точки; точки на расстоянии ≤ R соединяются линиями; замкнутый
контур **захватывает** чужие точки внутри — они гаснут и идут в счёт хозяина
контура. Побеждает тот, у кого больше захваченных точек к концу партии.

Имя «Euler» — в честь Леонаарда Эйлера (Euler): игра живёт в мире планарных
графов, контуров и обхода граней.

## Две версии

| Версия | Платформа | Стек | Папка |
|--------|-----------|------|-------|
| **MAID** | Десктоп (Linux/macOS/Windows) | Python + pygame-ce | [`MAID/`](MAID/) |
| **Android** | Мобильная (Android 7.0+) | JavaScript + Canvas + Capacitor | [`ANDROID/`](ANDROID/) |

Обе версии используют **одно и то же ядро** (перенос 1:1, покрыт
дифференциальными тестами). Правила и механика захвата совпадают.

## Правила (кратко)

* Ходят по очереди: красные, затем синие.
* Точки на расстоянии ≤ R соединяются линией.
* Замкнутый контур захватывает чужие точки внутри: они неактивны навсегда и
  идут в счёт захватившего (без оживления).
* Точка, поставленная внутрь чужого контура, **захватывается сразу**
  (самопожертвование).
* Точка, стоящая на линии контура, считается внутри.
* Побеждает тот, у кого больше захваченных.

### MAID (десктоп)

Запуск:
```
cd MAID
python3 -m venv --copies .venv      # один раз (на NTFS обязательно --copies)
./.venv/bin/pip install pygame-ce
./.venv/bin/python dotgame_maid.py
```
Режимы: `--ai` (компьютер за синих), `--aibot`/`--demo` (обе стороны).
Управление: ЛКМ — поставить, ПКМ — выбрать линию/круг и его пересечения,
колесо — зум, LMB-drag — панорама, Z — undo, R — reset.

### Android (мобильная)

Готовый APK: [`ANDROID/dotgame-android-v1.2.apk`](ANDROID/dotgame-android-v1.2.apk)
— скопируйте на телефон и установите.

Управление (сенсорное, два тапа):
* **Тап** — призрак (видно, куда встанет точка); **второй тап рядом** —
  подтвердить.
* Призрак сам подсвечивается: **жёлтый** — на своей линии/круге или на
  границе карты, **зелёный** — на пересечении своей линии/круга со своей,
  чужой линией или границей карты.
* Перетаскивание — панорама, щипок — зум (до ×100), два быстрых тапа — undo.

Сборка APK описана в [`ANDROID/README.md`](ANDROID/README.md) (нужны
Node 18+, JDK 21, Android SDK).

## Тесты

Ядро покрыто тестами в обеих папках:
* `MAID/test_maid.py` — логика (64 проверки).
* `MAID/stress_test.py` — усиленное: дифференциальный предикат «точка в
  контуре» на 6000 позициях / 50k запросов + инварианты на 14 400 ходах.
* `MAID/smoke_maid.py` — программный smoke живого UI-цикла (51 проверка).
* `ANDROID/test/` — дифференциальные тесты порта Python→JS (ядро идентично).

Подробности — в `MAID/README.md` и `ANDROID/README.md`.
